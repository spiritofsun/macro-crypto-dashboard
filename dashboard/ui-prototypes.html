UI Direction Review

운영 페이지 전환 전, 5개 후보 UI

현재 문제는 크립토 페이지와 나머지 페이지의 구조가 다르고, 구형 다크 컴포넌트가 일부 남아 있는 것입니다. 아래 후보 중 하나를 선택하면 공통 레이아웃, 카드, 표, 데이터 상태, 뉴스 영역을 같은 문법으로 통합할 수 있습니다.

대상 전체 페이지 방식 공통 템플릿 목표 화이트 UI 통일

추천 판단 기준

선택 후 전체 반영
데이터 가독성표, 수치, 지연 상태가 한눈에 보여야 함
카테고리 통일성크립토, 주식/매크로, ETF, 뉴스가 같은 구조를 공유
운영 효율업데이트 실패와 병목을 UI에서 바로 노출
개성일반 대시보드가 아닌 개인 리서치 사이트 느낌
